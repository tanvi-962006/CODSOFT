# CodSoft Web Development Internship

This repo has all 3 tasks I completed during my **Web Development Internship at CodSoft** (Level 1). Built using HTML, CSS and JavaScript.

---

## Tasks

### Task 1 - Calculator

A basic calculator using HTML, CSS and JavaScript. It has a display screen to show input and results, buttons for all arithmetic operations (+, -, ×, ÷), and I used CSS Grid for the button layout. The logic handles things like preventing double operators and showing errors for invalid expressions.

**What I implemented:**
- AC button to clear everything, DEL to remove last character
- Digits 0-9, decimal point, and double zero (00)
- Operator buttons styled in orange to stand out
- Dark theme with rounded buttons
- Used `eval()` for expression evaluation with proper error handling

**Folder:** `Calculator/`

---

### Task 2 - Landing Page

Made a Netflix India landing page clone. The idea was to practice layouts, sections, and responsive design. I focused on getting the look as close to the real Netflix page as possible.

**What I implemented:**
- Hero section with background image, sign-in button, and email signup form
- Trending section with horizontally scrollable movie cards (numbered 1-10)
- Left/right scroll buttons that hide/show based on scroll position
- "More reasons to join" feature cards with gradient backgrounds
- FAQ boxes
- Footer with links grid
- Responsive - works on desktop, tablet, and mobile

**Folder:** `Landing Page/`

---

### Task 3 - Portfolio

My personal portfolio website. This one took the most effort since I wanted it to look really good. Used a dark theme with purple-pink gradient accents throughout.

**What I implemented:**
- Hero section with my name and a short intro
- About section with my photo and bio
- Skills section - cards with progress bars for each skill (HTML, CSS, JS, Tailwind, Bootstrap, Node.js, MongoDB, Figma)
- Projects section showcasing my Spotify Clone and Netflix UI Clone
- Resume download section
- Contact section with email, LinkedIn, and GitHub links
- Scroll animations using Intersection Observer
- Mobile responsive with hamburger menu

**Folder:** `Portfolio/`
